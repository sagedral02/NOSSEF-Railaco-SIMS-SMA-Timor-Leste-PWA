# ADR-007: IPA/IPS Major model

- Status: Accepted
- Date: 2026-10-15
- PRD: §76

## Context

PRD INV-05 fixes majors to IPA and IPS. NOSSEF uses the local names Ciências e Tecnologias (CT) and Ciências Sociais e Humanidades (CSH).

## Decision

Major codes are `IPA` and `IPS` (stable machine values). The display name carries the local label, e.g. `IPA — Ciências e Tecnologias (CT)`. No other stream model is introduced.
